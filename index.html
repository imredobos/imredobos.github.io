Overview Widget iframe

Hello Tamas — a cross-origin host page for the two ways of putting a Zocks booking page on somebody else's site, one per page so they can be compared against each other.

Widget

Loads /embed/v1.js and calls Zocks.initWidget() twice: once inline, once as a popup. The host page gets onReady, onResize, onStepChange, onBookingConfirmed and onError back.

Open /widget →

iframe

A plain <iframe> pointing straight at the booking page. No script on the host page, and no visibility into what happens inside the frame.

Open /iframe →

What both pages point at

Defaults live in assets/config.js. Either page accepts ?base=, ?account=, ?user= and ?eventType=, so one deploy can demo any booking page.

Before either page works here

This is a genuinely cross-origin host, so the account's embed allowlist has to contain imredobos.github.io. As of the last check the booking page still answers frame-ancestors 'self', so the browser blocks the frame: /widget degrades to the widget's own "Open the booking page" link after its 4s timeout, and /iframe shows nothing but the browser's blocked-frame error.

For a local app, point the demos at it with ?base=http://localhost:3000 and add localhost to allowedDomains.
